# Evidence Integrity Checker

A Python forensic tool for maintaining digital evidence integrity 
using SHA256 hashing and chain of custody documentation.

## Features
- Register evidence files with SHA256 hashing
- Detect file tampering through hash comparison
- Generate chain of custody reports
- Forensic audit logging with timestamps
- Severity levels tied to legal consequences
- Case number tracking (Kenya DCI format)

## Built With
- Python
- hashlib (SHA256)
- JSON registry
- logging module

## Use Case
Digital forensics investigations requiring evidence integrity 
verification under Kenya's Computer Misuse and Cybercrimes Act 2018.
